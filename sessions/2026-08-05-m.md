# Session 2026-08-05 (m) — Cost/sell toggle only reached one of two "Import from PDF" buttons; found and closed the gap

## Built

- **Root-caused a "the cost/sell fix from earlier doesn't work" report from Royce without guessing.** His first message ("draf PDF doesnt appear to work... not from main menu or isnsidfe the new quote menu") was genuinely ambiguous between the new PDF-import feature and the unrelated pre-existing "Download PDF" quote-export feature — asked a quick clarifying question rather than investigating the wrong system, confirmed it was the import side.
- **Investigated with live evidence before writing any code**: Sentry showed zero errors on this path (ruled out a client or server crash); a direct unauthenticated probe of `quote-parse-subcontractor` confirmed the live function was reachable; pulled the actual deployed `EqOps-*.js` bundle from core.eq.solutions and grepped it for this session's own literal UI strings, confirming all three earlier PRs (#1248/#1249/#1252) really were live in production, not a stale-deploy issue.
- **Royce's follow-up message narrowed it precisely**: "cost vs sell import only works on main menu From PDF button - not from inside new quote (import PDF) need to wire that." Traced to a real, distinct gap: `QuotesModule.tsx`'s New Quote form has a *second*, separate "Import from PDF" button (`quote-parse-pdf.ts`, the client-RFQ parser) that #1252 deliberately left alone — its schema already asks the AI for `cost` and `rate` as two independent fields, which is correct when a document states both, but still forces a guess when a document only shows one price column per line. Same underlying ambiguity as the subcontractor path, just happening inside the AI extraction instead of on the client.
- **Fix**: a per-line ambiguity check — both fields present, or neither, applies exactly as before (no extra click for the common case). A line with only one of the two now triggers a compact confirm modal (shown only when at least one line actually needs it) asking Cost or Sell, reusing `computeCostFromSell`/`computeSellRate` from #1252. eq-shell [PR #1254](https://github.com/eq-solutions/eq-shell/pull/1254), squash-merged, all CI green including `typecheck·test·lint`.
- **Memory corrected**: `pdf-quote-import.md` was stale (still described the "start quote from PDF" idea as a future plan; it shipped weeks ago). Rewrote it around the actual durable trap — two separate "Import from PDF" buttons with different backends, easy to conflate, is exactly what caused today's back-and-forth.
