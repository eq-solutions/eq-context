- **Plain-language pass** — the DAMA-framework dimension names (Validity/Consistency/Timeliness/Serviceability) became "Correctly formatted / Records linked up / Recently updated / Ready to dispatch" (technical term kept as a hover tooltip); the To Do duplicate-category hint was rewritten out of engineer-register.
- **Checked, not blindly "fixed": the two on-demand scans (Duplicates, Record age).** Verified live why they're opt-in rather than auto-run alongside the other four Overview checks — `computeHealthScores`, `detectAllDuplicates`, and `decayCheck` each independently re-fetch all 5 entities via the same RPC, so auto-running all three would triple the per-load data transfer plus add the duplicate detector's own O(n²) pairwise comparison cost. Left the click-gate in place, added a one-line caption instead so the inconsistency reads as intentional, not broken.
- **Reconcile fold-in** — confirmed the inline "Check for conflicts" panel was already correctly folded into Bring Data In (no redundant heading/dropzone in scoped mode); fixed a stale comment claiming otherwise and gave the panel a proper card style so it reads as part of the flow.
- eq-solves-intake [PR #111](https://github.com/eq-solutions/eq-solves-intake/pull/111), merged (squash `c50c486`).
- **Fuzzy-match Reconcile** — closed a real, previously-unbuilt backlog item (`pending.md`, added 2026-07-02): `reconcile.ts`'s conflict detection was exact-key only, so a near-duplicate with no shared key value — "Acme Pty Ltd" in a dropped file vs "ACME P/L" already in EQ — silently fell through as an unrelated "new row to add" next to an "untouched" canonical row instead of getting flagged. Reused the Dice-coefficient matcher already built/tested for the duplicate detector (extracted `identityKeyFor`/`identityLabelFor` out of `duplicate-detect.ts`'s private logic, zero behaviour change, its 11 existing tests still pass) rather than reimplementing fuzzy matching a second time. `reconcileSheets()` takes an optional `entity` param; matched pairs promote into `conflicts` with `matchedBy: "fuzzy"`. UI never offers an automatic "use source" merge on a fuzzy row (single or bulk) — no shared key to upsert against, so it would silently insert the duplicate the feature exists to prevent.
- **Found and fixed in the process, not assumed**: verified the backlog item's own flagship example against the real normaliser before writing the test — "Acme Pty Ltd" vs "ACME P/L" only scored 0.6 similarity (below the 0.85 match bar) because `normaliseCompanyName` didn't recognise "P/L" as the standard Australian shorthand for "Pty Ltd." Extended the legal-suffix regex; re-verified the pair now normalises identically.
- 6 new tests (`reconcile.test.ts`); full suite green (25 files, 164 tests); both packages' `tsc --noEmit` clean throughout. eq-solves-intake [PR #112](https://github.com/eq-solutions/eq-solves-intake/pull/112), merged (squash `7d98384`).
