# Session 2026-08-05 — eq-field: Birthdays & Anniversaries dashboard widget fixed (intermittent → self-healing)

## Built
- Root-caused Royce's report ("birthdays and anniversaries show up on the main dashboard but not everytime"): the widget depends on `people.js`, lazy-loaded only by Roster/Editor/Schedule/Contacts/person-wizard — Dashboard (the landing tab) never triggers it, so the widget's `typeof` guard silently blanked with no retry whenever the user hadn't visited one of those other tabs first that session.
- Fixed by adding a self-heal kick to `renderDashboard()` (`scripts/dashboard.js`), mirroring the existing leave-strip kick pattern (v3.5.293): lazy-loads `people.js` in the background on first dashboard render, re-renders both the Birthdays & Anniversaries and Starting Soon widgets once it lands.
- Shipped as eq-field v3.5.458, [PR #653](https://github.com/eq-solutions/eq-field/pull/653), squash-merged to main (`e29186d`). Netlify auto-deploys `main` → field.eq.solutions.

## Notes
- Local verification hit a real environment limit worth remembering: `npx serve` (this repo's `.claude/launch.json` dev-server config) is a plain static file server and can't run `netlify/functions/tenant-config.js`, which Field's boot sequence needs to resolve tenant routing. Every local preview attempt therefore dead-ends on "Cannot reach the configuration service" before the dashboard ever mounts. Worked around it by testing the actual (unmodified) render functions directly via the browser JS console — seeded `STATE.people`, reproduced the blank-widget bug, then fired the real kick logic and confirmed it self-heals — rather than trying to fake a full boot.
- On the real Netlify deploy preview, `tenant-config` does work (200, confirms no regression), but `?tenant=demo` didn't activate on the `deploy-preview-*.netlify.app` subdomain — it fell back to the real `eq` tenant, which is Core-only auth (per this repo's CLAUDE.md) and has no click-through path without a real Shell sign-in. Pre-existing behaviour, unrelated to this fix; not chased further.
