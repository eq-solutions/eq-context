- **Royce's stated preference, worth remembering for any future "make this UI element show up" report**: when a display bug has multiple possible fixes ranging from a one-line change to a page-level rebuild, default to proposing the simplest one first and only escalate in scope if asked — don't lead with the "most correct" architectural option.
