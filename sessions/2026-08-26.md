# Session 2026-08-26 — QR sign-in confusion: placeholder fix + a real repeat-login root cause found and fixed live

## Built

Fixed on both mobile-number inputs in `LoginPage.tsx` (send-code and PIN-login variants): placeholder now reads `Enter mobile number`.
